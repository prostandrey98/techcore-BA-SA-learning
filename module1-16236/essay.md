
# Модуль 1. Введение в бизнес- и системный анализ

## Задание: Запуск доставки для кофейни

### Цель проекта
Создать сервис онлайн-заказа и доставки кофе.

### Задачи бизнес-аналитика (BA)

1. Определить потребности клиентов.
2. Изучить проблемы бизнеса.
3. Собрать бизнес-требования.
4. Оценить ожидаемую выгоду.
5. Согласовать цели с заказчиком.

### Задачи системного аналитика (SA)

1. Описать функциональные требования.
2. Спроектировать взаимодействие систем.
3. Определить структуру данных.
4. Описать API для заказов.
5. Подготовить техническую документацию.

## Вывод

BA определяет, что и зачем нужно бизнесу.
SA описывает, как система должна это реализовать.
